# 每一步的验收清单

看完就知道这步能不能往下走。**机器能查的标了 🤖，必须人看的标了 👁。**

---

## 1 选题

- [ ] 🤖 三个坑都能对上具体画面（不是"我觉得能拿到"）
- [ ] 🤖 一句话结论能单独成立，不依赖上下文
- [ ] 👁 这条选题，目标受众会点开吗
- [ ] 👁 同赛道有没有人做过？我比他们多什么

**不过就不能写稿。**

## 2 素材

- [ ] 🤖 实机录屏占比 ≥ 50%
- [ ] 🤖 素材类型 ≥ 3 种（截图 / 录屏 / 图表 / 空镜）
- [ ] 🤖 同一素材复用 ≤ 3 次
- [ ] 🤖 引用的素材文件全部存在
- [ ] 👁 每个坑都有画面对应的证据
- [ ] 👁 "怎么装、怎么启动、怎么跑出第一个结果"三段齐全

**不过就不能进装配。**

## 3 写稿

- [ ] 🤖 第一句是判断，不是背景
- [ ] 🤖 每段台词都能指向一个具体对象
- [ ] 🤖 全片有一句能被单独引用的结论
- [ ] 👁 念一遍，有没有拗口的
- [ ] 👁 三个坑有没有编号（坑一/坑二/坑三）

## 4 配音

- [ ] 👁 **亲耳听完每一句**（这是唯一标准，没有机器指标）
- [ ] 👁 关键词有没有重读
- [ ] 👁 停顿是否自然，有没有一口气念完长句
- [ ] 🤖 音频时长和字幕时间轴误差 < 0.3 秒

**没听完就往下走，等于白做。**

## 5 装配

- [ ] 🤖 `node scripts/gate.mjs` PASS
- [ ] 🤖 `node scripts/tool.mjs align` 通过
- [ ] 🤖 没有黑帧、没有超长镜头
- [ ] 👁 抽 5 个关键帧看：开场、三个坑、结论、结尾
- [ ] 👁 静音看一遍——只看画面能不能懂
- [ ] 👁 闭眼听一遍——只听声音能不能懂

**这两遍是分开的，一起看会漏掉一半问题。**

## 6 发布

- [ ] 👁 封面能让人在 1 秒内知道讲什么
- [ ] 👁 标题有具体数字或反常识
- [ ] 🤖 三个平台文案都生成了
- [ ] 👁 平台规则检查（字数、标签数、敏感词）
- [ ] 👤 **人点发布**（这一步永远不由机器做）
