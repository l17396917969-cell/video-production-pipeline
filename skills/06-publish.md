# 发布

**输入**：成片 + `episode.json`
**输出**：`episodes/<期号>/publish/{douyin,bilibili,shipinhao}.md` + `cover.png`

## 封面

封面统一用组件库做，不另开一套设计：

- 16:9 主封面：`T01` 改文案，字号压到 96，kicker 放栏目名
- 竖版封面（抖音）：另存一版 1080×1920
- **一次出 3 版**，标题不同角度，人挑一版

## 文案

```bash
node scripts/publish.mjs episodes/0001
```

会自动裁到各平台字数上限：

| 平台 | 标题上限 | 简介上限 | 标签 |
| --- | --- | --- | --- |
| 抖音 | 55 | 500 | 5 个话题 |
| B站 | 80 | 2000 | 10 个 |
| 视频号 | 30 | 1000 | 3 个 |

## 最后一步：人点发布

各平台没有稳定官方上传接口。三条路：

1. **人工**：复制 `publish/*.md`，粘贴。最稳。
2. **huimei**（`pipx install huimei`）：CLI + MCP，支持抖音/B站/视频号，需要登录取号。适合要批量发的人。
3. **Playwright 半自动**：`scripts/record.mjs` 那套可以改造成"打开创作者后台 → 填表 → 停下来等人点发布"。**不要自动点。**

## 禁止

- 禁止自动点发布按钮
- 禁止三个平台用同一份文案（字数限制和语气都不一样）
- 禁止标题党到和内容对不上（完播率会崩）
